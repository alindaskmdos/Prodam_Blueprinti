# Дизайн: Graphite

Выбранный вид фронта — тёмный, по концепту слайда 4. Живые макеты (с анимациями и кликабельными вкладками):
https://claude.ai/artifact/NM28oRLyAk7LChLDfBMKR3 — страница «Экраны · Graphite».

Файлы `*.dc.html` — исходники макетов. Напрямую в браузере они не рендерятся (нужен рантайм макета),
но читаются как HTML+CSS: разметка, inline-стили, `@keyframes` в `<helmet><style>`. Брать отсюда цвета, размеры, тексты и анимации; React-компоненты писать заново.

## Токены (в FE-01 вынести в `tokens.css`)

Фон `#0B0E13`, шапка `#0E1218`, панель `#11151B`, поднятый `#161B23`, выбрано `#1B2532`, граница `#1F2630`/`#2A323E`.
Текст `#E6EAF0`, вторичный `#9AA4B2`. Акцент `#5B9BFF`, успех `#4ADE80`, высокая `#F87171`, средняя `#FBBF24`, «возможно» `#A9C6FF`.
Ноды: method `#8B5CF6`, var `#60A5FA`, assign `#93C5FD`, expr `#22D3EE`, if `#FBBF24`, for/foreach `#A78BFA`, while/dowhile `#C4B5FD`, switch/case `#FB923C`, try/catch `#F87171`, throw `#FCA5A5`, return `#4ADE80`, break/continue `#94A3B8`, comment `#FDE68A` (стикер), raw — пунктирная рамка `#5E6878`.
Шрифты: Inter (интерфейс), JetBrains Mono (код, выражения, Big O).

## Анимации

rise 500 мс (появление, каскад 60 мс) · flow 900 мс ∞ (пунктир по стрелкам) · pulse 1,8 с ∞ (нода с проблемой) · pop 450 мс (галочки) · fill 900 мс (прогресс) · shake 500 мс (фикс не подтверждён) · hover 150–180 мс. Всё отключается при `prefers-reduced-motion`.
