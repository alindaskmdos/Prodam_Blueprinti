# Идеи (бэклог)

Не входят ни в обязательный минимум, ни в «если успеем». Брать только по решению людей.

- Счётчики выполнения на нодах и тепловая карта (инфраструктура уже есть после «покрытия», §14а.6)
- Эмпирическая проверка Big O по счётчикам выполнения (детерминированно, без замера времени)
- Путь сложности «почему O(n²)» — подсветка цепочки нод
- Диф графов «до/после» фикса
- Мутационное тестирование lite («тесты ловят N% изменений»)
- Генерация входов по вызовам Scanner без LLM
- Слайдер n с графиком оценки операций до/после
- Метрики классов с оценками A–E (цикломатическая/когнитивная сложность, CBO, LCOM)
- Поток исключений
- Утечки ресурсов (незакрытый Scanner и т.п.)
- Рекурсия через рекуррентные соотношения (основная теорема)
- Модернизация до Java 21 (record, switch-выражения, Stream)
- Пользовательский конфиг правил `blueprints.yml`
- Именованные снимки и откат по ленте версий
- Экспорт изменений как unified diff
- SonarQube как опциональный профиль docker-compose
- Декомпиляция .jar с .class (Vineflower)
