# Frontend — правила

React + TypeScript (Vite), React Flow (xyflow) + ELK.js, Monaco Editor, MSW для моков.
ТЗ: §6 (редактор нод), §7 (структура проекта), §8.4 (отображение анализа), §10 (тесты), §12 (API и синхронизация).
Ориентир по виду — концепт со слайда 4 кейса (тёмная тема), ноды в стиле Unreal Blueprints.

## Структура (`src/features/*`)

| Фича | Что |
|---|---|
| `api` | сгенерированные типы (`npm run gen:api` из `contract/openapi.yaml`) + клиент |
| `editor-nodes` | React Flow, раскладка ELK, ноды, палитра |
| `editor-code` | Monaco, синхронизация с нодами |
| `project-tree` | дерево проекта, формы классов/полей/методов |
| `analysis-panel` | вкладки Проблемы / Предупреждения / Метрики |
| `tests-panel` | IO-тесты, JUnit в Monaco, результаты, diff |
| `upload` | загрузка файлов/архивов/папки, предупреждения загрузки, экспорт |
| `diagrams` | UML, граф зависимостей классов (если успеем) |
| `console` | терминал xterm.js (если успеем) |
| `debug` | пошаговое воспроизведение (если успеем) |
| `command-palette` | Ctrl+K: поиск и команды (если успеем) |

Вкладки панелей регистрируются списком (`panels.ts`) — новая вкладка = новый элемент списка. Пользовательские действия (кнопки «Запуск», «Экспорт» и т.п.) регистрируются в `commands.ts`, чтобы они сразу были доступны в командной палитре.
В каждой фиче — `README.md` на 10–20 строк.

## Правила кода

- Типы API **только** из `src/features/api/generated`. Руками типы ответов не писать.
- Пользователь **не рисует стрелки**. Структура меняется только операциями над деревом: вставка через «+» на стрелке или drop из палитры на стрелку, удаление, вверх/вниз, правка текста.
- Отправляй **полное** дерево изменённого метода, не диффы. Храни версию проекта; на 409 — перезагрузи состояние.
- Текстовые поля нод — с подсветкой синтаксиса Java (лёгкий редактор, не полный Monaco на каждую ноду).
- Невалидный текст в ноде (ответ бэка) → нода красная, правка не считается применённой.
- Правка в Monaco → debounce 500 мс → запрос.
- Контейнеры (циклы, if, try, switch) сворачиваются; при вложенности > 3 — свёрнуты по умолчанию. Мини-карта включена. Переключатель «показывать комментарии».
- Оценка сложности показывается как «≈10⁸ → ≈10⁴ операций при n = …» с подписью «асимптотическая оценка». «Ускорение в X раз» — только из результата замера.
- Режим мок/бэк — переменная `VITE_USE_MOCKS`. Моки читают `contract/fixtures/`.

## Проверки

`npm run typecheck && npm run lint && npm test` перед коммитом.
